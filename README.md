# AI Explainers

A personal library of explainers and visualizations about machine learning, data science, large language models, and artificial intelligence.

Save Markdown (`.md`) and HTML (`.html`) files here, along with any images or other assets they need. Use descriptive filenames, and group related files in topic folders as the collection grows.

## View visualizations

Open the collection at https://palpen.github.io/ai-explainers/.

GitHub Pages publishes the files from the root of the `main` branch after each push. HTML files can be opened directly using their filename, such as https://palpen.github.io/ai-explainers/coding-agent-loop.html. Add links to new visualizations in `index.html` so they appear on the collection's home page.

Markdown files remain source documents; this static site does not convert them to HTML.

## Version history

This folder is a local Git repository. After adding or editing files, save a version from this folder with:

```sh
git add .
git commit -m "Describe what you added or changed"
```

View saved versions with `git log --oneline` and pending changes with `git status`.

The repository is backed up on GitHub at https://github.com/palpen/ai-explainers. After committing, run `git push` to sync your saved versions and publish the site updates.
